# kempo-products-inventory

Connects [kempo-products](https://github.com/dustinpoissant/kempo-products) to [kempo-inventory](https://github.com/dustinpoissant/kempo-inventory). Sell a model car and the resin, paint and filament it is made from come out of stock automatically, and the products that can no longer be made go out of stock with it.

**Status: design only.** Nothing is built yet. Read [PLAN.md](PLAN.md).

Neither of those extensions needs the other. Install this one when you use both.
