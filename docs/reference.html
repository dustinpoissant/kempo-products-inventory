Reference

HTTP API

JSON routes under /products-inventory/api/. They need the products and inventory permissions named on the install section.

RoutePurpose
GET linksEverything linked (?productId= or ?inventoryItemId= narrows it), with names and stock
PUT linksReplace what a product is made from: { productId, links: [{ inventoryItemId, quantity, optionKey?, choiceKey? }] }
POST recalculateRecalculate every linked product
GET problems, DELETE problems/<id>What needs attention, and dismissing it
 
await fetch('/products-inventory/api/links', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    productId: 12,
    links: [
      { inventoryItemId: 3, quantity: 175 },
      { inventoryItemId: 7, quantity: 20, optionKey: 'color', choiceKey: 'red' },
    ],
  }),
});

What it listens to

EventAnd
kempo-products:purchase:recordedtakes the materials out of inventory in one atomic call
kempo-products:purchase:reversedputs back what that purchase took
kempo-inventory:stock:adjustedrecalculates every product made from that item
kempo-products:product:deletedforgets what the product was made from
kempo-inventory:item:before_deleterefuses while products are made from the item

What it uses

  • From kempo-products: setStock, setManagedBy and setChoiceAvailability.
  • From kempo-inventory: adjustStockMany.
  • Interface: the Made from tab on a product's form (global content pushed into the products-admin-product-tabs location), the Make product from this item panel on an item's page (inventory-item-actions), and the admin pages.

Tables

TableHolds
linkA product, an inventory item, the amount per unit, and optionally the option and choice it applies to
deductionWhat each purchase took, by reference, so a reversal puts back exactly that
problemPurchases whose materials could not be taken, until dismissed

Uninstalling drops these tables. The products and inventory items themselves are not touched.

Development

npm run link:local          # symlinks the sibling kempo checkouts
docker compose up -d        # a throwaway Postgres on port 5444
DATABASE_URL=postgresql://kempo:kempo@localhost:5444/kempo_products_inventory_test npx drizzle-kit push --force
DATABASE_URL=postgresql://kempo:kempo@localhost:5444/kempo_products_inventory_test npm test

The database tests run the whole chain with the real hooks registered: a purchase in kempo-products takes materials out of kempo-inventory, and products made from them follow. They skip themselves when no database is reachable and refuse to run unless its name ends in _test. A green run with SKIPPED did not test the database.

The documentation is written in docs-src/ and built into docs/ for GitHub Pages. Edit docs-src/, then run npm run docs:build. npm run docs:dev serves it on port 4051.
